# General Strategies

Got a hard problem? See if you can replace it with an easy problem!

Introduce a new problem with a pre-planned solution that yields progress.

----------

Introduce behavior incompatible with a given problem.
Even if the new behavior is problematic in its own right,
so long as that new problem is easier to solve than the first.
